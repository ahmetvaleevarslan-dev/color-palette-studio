# Supabase

ColorStudio использует Supabase для авторизации, избранных цветов и пользовательских палитр.

## Что нужно настроить

- Authentication для регистрации и входа пользователей.
- Таблицу `favorite_colors` для избранных цветов.
- Таблицу `user_palettes` для сохранённых палитр.
- Row Level Security (RLS), чтобы пользователь видел и изменял только свои данные.

## Клиентская конфигурация

Параметры проекта находятся в `config.js`.

В клиентском коде допустимо использовать только публичный publishable/anon key. Никогда не размещай service role key в браузерном коде или публичном репозитории.

## Безопасность

Проверь RLS перед публикацией приложения. Пользовательские записи должны быть привязаны к `auth.uid()`.
