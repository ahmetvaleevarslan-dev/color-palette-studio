# 🎨 ColorStudio

**ColorStudio** — современный веб-инструмент для работы с цветом, созданный для веб-дизайнеров и frontend-разработчиков.

🔗 **Repository:** https://github.com/ahmetvaleevarslan-dev/color-palette-studio

## ✨ Возможности

- 🎨 24+ готовых цветовых палитр
- 🔎 Поиск цветов по HEX, RGB, HSL и названию палитры
- 🧪 Лаборатория цвета и генерация гармоничных палитр
- 🎯 Проверка контрастности по WCAG
- 🖼️ Извлечение основных цветов из изображения
- 🌈 Генератор CSS-градиентов
- ⭐ Избранные цвета
- 💾 Сохранение собственных палитр
- 👤 Регистрация и авторизация
- ☁️ Синхронизация избранного и палитр через Supabase
- 📱 Адаптивный интерфейс для компьютеров и мобильных устройств

## 🛠️ Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- Supabase

## 🚀 Запуск

Проект не требует сборщика. Открой `index.html` через локальный сервер или размести репозиторий на GitHub Pages.

Для локального запуска удобно использовать VS Code + Live Server.

## 🌐 GitHub Pages

1. Открой **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выбери `Deploy from a branch`.
3. Выбери ветку `main` и папку `/ (root)`.
4. Сохрани настройки.

После публикации GitHub Pages выдаст публичный адрес проекта.

## 🔐 Supabase

Авторизация, избранное и пользовательские палитры работают через Supabase. Подробности настройки находятся в `docs/SUPABASE.md`.

> Никогда не добавляй в репозиторий секретные server-side ключи. Для клиентского приложения используй только публичный ключ Supabase.
